# Content Package: AI 记忆 > AI 模型

## Core Thesis
模型是消耗品，记忆是壁垒。你的 AI 助手应该记住你，而不是被平台绑架。

## Key Points (3 points for 60s short)

### 1. 模型是消耗品
GPT-4 → 4o → 5，Claude 3 → 3.5 → 4。每 3 个月换一代。但你上个月的决定、你的偏好、你踩过的坑——这些不能重来。模型像手机，年年换新。记忆像日记，越写越厚。

### 2. 平台记忆 = 人质
ChatGPT Memory、Claude Memory 都把你的记忆锁在他们的服务器。不能导出，不能迁移。换模型那天 = 从零开始。50K 人给 MemPalace 点了 star，因为 AI 失忆不只是开发者的痛。

### 3. 自主记忆才是出路
你的记忆应该在你手上。本地文件、私有 repo、你能迁移。模型随便换，记忆跟着你走。这不是技术选型——这是数据主权。
