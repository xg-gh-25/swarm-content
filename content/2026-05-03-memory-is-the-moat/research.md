# Research: AI 记忆 > AI 模型

## Thesis
所有 AI 系统里，模型会换、框架会换、功能会换，但**你积累的记忆不会换**。谁拥有记忆，谁就拥有锁定。

## Differentiation Angle
市场上所有人都在比模型（GPT-4o vs Claude 4 vs Gemini）、比框架（LangChain vs CrewAI vs AgentCore）。我们重新定义比赛：**不比模型，比谁记得住你**。

## Competitive Landscape (first-hand analysis)

| Player | Memory Approach | Lock-in Risk |
|--------|----------------|-------------|
| ChatGPT | 平台 Memory（OpenAI 控制 schema/lifecycle） | 高 — 你走不了带不走 |
| Claude | 刚推 Memory，平台控制 | 高 — 同上 |
| SwarmAI | Self-sovereign（MEMORY.md + DailyActivity + FTS5） | 零 — 全在你本地 |
| MemPalace | Local-first，50K stars in 27 days | 低 — 但纯消费端 |

## Key Evidence (6 sources converging)

1. **CrewAI 创始人 João Moura**: "Entangled software — behavior-bound, not feature-bound" = memory
2. **Karpathy**: "You can outsource thinking, not understanding" — understanding = accumulated memory
3. **LangChain + CrewAI founders independently**: memory is the moat (2026-04-18)
4. **AgentCore Memory API**: 故意不提供 export = strategic lock-in
5. **Cat Wu / Claude Code**: "95% automation ≈ 0% automation" — the 5% = user context = memory
6. **MemPalace 50K stars in 27 days**: Market demand for AI memory is explosive

## Audience Hook
"你换了 Claude 4，上周的对话记忆全没了。你的 AI 有记忆吗？还是每次都从零开始？"

## 3 Key Points for 60s Short
1. **模型是消耗品** — GPT-5 出来 GPT-4 就不用了。但你上个月的决定、你的偏好、你团队的 context —— 这些不能重来。
2. **记忆是锁定** — ChatGPT Memory / Claude Memory 都把你的记忆锁在他们平台。换模型 = 失忆。
3. **自主记忆是出路** — 你的记忆应该在你手上（本地文件、你能导出、你能迁移）。模型随便换，记忆跟着你。
