# Narrative Track Spec

## Source
PR/FAQ full rewrite → first-person builder narrative

## Target
- 公众号长文 (1500-2500字)
- B站动态 (精简版 300字)
- 小红书短文 (200-500字, 配合 poster)
- GitHub README section (英文, 200 words)

## Narrative Arc
1. **Hook** — "上周我打了一句话，收到了5个平台的视频。这不是demo。"
2. **Pain** — 技术人做内容的 20 步地狱（写→录→剪→封面→适配→文案→发布×5）
3. **Insight** — 内容生产是工程问题不是创意问题。当每步有明确输入输出和质量门控时，AI 能端到端驱动。
4. **Solution** — Pollinate 9 阶段 Pipeline（重点讲 STRATEGIZE：不是你选格式，是 AI 根据受众选格式）
5. **Proof** — 自我指涉："你正在看的这篇文章+那张海报+B站动态，全是这一次 Pollinate 运行的产出"
6. **Architecture** — 简版系统架构（PR/FAQ → Channel Matrix → Parallel Tracks → Per-Channel Deliver）
7. **CTA** — GitHub: xg-gh-25/SwarmAI | 小红书: Swarm-Blabla

## Tone
Professional-casual. 第一人称。"我造了这个" 不是 "我们很高兴地宣布"。
直接、有观点、有具体数字。不要 marketing speak。

## Word Count Targets
- 公众号: 2000字
- B站动态: 300字
- 小红书: 300字
- GitHub README: 200 words (English)
