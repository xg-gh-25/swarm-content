# FAQ

**Q: Hive 和桌面版有什么区别？**
A: 几乎没有。同一套代码，同一套技能（61个），同一套记忆系统。唯一区别是 Hive 跑在 EC2 上，通过浏览器访问，24/7 在线。

**Q: 数据安全吗？**
A: Hive 部署在你自己的 AWS 账号。HTTPS 加密（CloudFront），Basic Auth 密码保护，Security Group 只允许 CloudFront 流量。没有 SSH 端口暴露，管理走 AWS SSM。你的记忆和对话存在 EBS 加密卷上，只有你能访问。

**Q: 多少钱？**
A: EC2 m7g.xlarge + EBS + CloudFront ≈ $128/月全天候。开启 12 小时自动休眠后约 $68/月。比任何 AI SaaS 订阅都划算 — 而且数据是你的。

**Q: 能给团队用吗？**
A: 可以。每个人独立部署一个 Hive 实例。你作为管理员可以推送共享知识（文档、项目），但每个人的对话和记忆完全隔离。
