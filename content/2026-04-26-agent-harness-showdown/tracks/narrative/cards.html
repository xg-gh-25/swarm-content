第一章 · 认知校准

先搞清楚：
你看的是哪一层？

市场上叫 "Agent" 的东西分属三个完全不同的层级，大部分对比文章把它们混在一起比——这是最大的误导。

L3 平台层
你定义 agent，我管 infra + runtime + memory + observability
AgentCore · Claude Managed Agents
L2 框架层
你管 infra，我给编排 + memory + tool 抽象
Hermes · LangGraph · CrewAI · DeerFlow 2.0
L1 产品层
开箱即用，终端用户直接交互
Claude Code · OpenClaw · SwarmAI · Operator

同层竞争是内卷，跨层是降维打击。
L3 的客户是 L2 和 L1。

🚨 核心观点

真正的战场：
你的记忆存在哪？

记忆是 Agent 唯一不可替代的资产。

模型可以换（改个 endpoint），工具可以换（MCP 是标准协议），编排可以换（都是 prompt loop）。但记忆——工作习惯、项目上下文、个人偏好、历史决策——是时间的结晶，不可重建。

  • 🔒 AgentCore — 无法导出
  • 🔒 Claude Managed — 无法导出
  • 🔓 Hermes — 本地，但 2.2K chars 上限
  • 🔓 OpenClaw — 本地 vector，可迁移
  • 🔓 SwarmAI — 本地 git，完全可迁移

AgentCore Memory API 故意不提供 export。这不是技术限制，是战略选择。
