# Swarm Pollinate — AI Content Production Engine

## Core Thesis
一个话题进去，5个平台的内容出来。Pollinate 是 Swarm 的内容生产引擎：8阶段 Pipeline 驱动，从选题评估到多平台发布全自动。

## Key Visual Elements (Poster)

### Hero Section
- 🐝 Swarm logo + "Pollinate" 标题
- Tagline: "Knowledge in, Content out, Spread everywhere."
- 副标题: "一个话题 → 5个平台"

### Pipeline Flow (核心视觉)
```
话题输入 → EVALUATE → THINK → PLAN → BUILD → REVIEW → TEST → DELIVER → REFLECT
   │                                                              │
   └──────────── 经验闭环 ←──────────────────────────────────────┘
```

### Build 阶段展开
- 📝 Script (podcast.txt + SSML)
- 🎙️ TTS (Amazon Polly Zhiyu/neural)
- 🎬 Remotion 4K render (3840×2160)
- 🖼️ Auto thumbnails (16:9, 4:3, 3:4)
- 📐 Vertical recut (generate_shorts.py)
- 🎵 BGM auto-mix (3% volume)
- 📋 Subtitles (SRT, native burn-in)
