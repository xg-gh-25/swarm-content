↕
LAYER 2 · INTELLIGENCE

没有 Layer 2+3，4 个文件就是普通文档 — 写完即死。
有了它们，文档成为自维护的活系统。

KNOWLEDGE PYRAMID

四层知识架构 — 逐级提纯

Tier 4 DDD (4 docs) — 项目权威知识 · 判断基础
Tier 3 Knowledge/ — 工作区通用知识 · 研究 · 参考
Tier 2 MEMORY.md — Agent 行为记忆 · 跨 session 持续
Tier 1 DailyActivity — 原始 session 日志 · 30 天 TTL

同一事实可以存在于多层 — 这是正确的，不是 bug。
每层服务不同消费者。DDD 是最高权威层。

CRITICAL DESIGN DECISIONS

不是最佳实践 — 是踩过坑后的选择

每条决策背后都有"为什么不这样做"的答案。

D1 — JUDGMENT, NOT DOCUMENTATION
DDD 是决策基础设施，不是文档系统
AI 不需要参考手册。它需要足够的结构化上下文来做正确的自主判断。每个 section 要么支持判断，要么防止已知错误。别的一概不放。
D3 — TIERED AUTONOMY
增量自动应用，风险人工审批
新 lesson 加到 IMPROVEMENT.md？自动。修改已有内容？排队等审批。Git 是安全网。80% 的知识变更零摩擦通过，20% 走安全门。用户不是审批者，是方向制定者。
D5 — HEALTH DRIVES AI TRUST
健康分数驱动 AI 信任度，不生成人类任务
Health score < 50？AI 不会来找你"去更新文档"。它会自己标注不确定性、减少对该 section 的依赖、优先 cultivation 更新。人类维护成本：零。
D6 — FOUR-TIER PYRAMID
有意的跨层重复 — 不同消费者，不同目的
DailyActivity = 今天发生了什么。MEMORY = agent 应该记住什么。DDD = 这个项目的判断依据。同一条 lesson 出现在三层 = 设计正确。永远不因为"已经在 MEMORY.md 里了"而抑制 DDD 提案。
D8 — PIPELINE IS DDD'S RICHEST FEED
Pipeline REFLECT 是最高价值信号源
每次 pipeline run 产生结构化 lessons：什么尝试了、什么成功了、什么失败了、为什么。比 session 对话高 3× 信号密度。飞轮最强的一条边。
